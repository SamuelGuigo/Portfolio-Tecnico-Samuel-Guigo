# Windows Server — Active Directory & DNS Infrastructure

Sanitized professional case based on infrastructure work performed as part of my role at **EGE Soluções**.

## Objective

Prepare Windows Server virtual machines for directory and DNS services inside a VMware-based business environment.

## What I worked on

I prepared Windows Server systems and the surrounding infrastructure required for Active Directory and DNS homologation.

Activities included:

- Windows Server deployment on virtual machines
- VMware Tools installation
- operating-system updates and reboots
- baseline system configuration
- Active Directory Domain Services preparation
- DNS service preparation
- infrastructure dependency mapping
- documentation of validation requirements
- planning for monitoring, backup and rollback

## Validation philosophy

I treat installation and production acceptance as different stages.

Before considering an AD/DNS environment production-ready, I expect evidence for items such as:

- directory health checks;
- replication validation;
- forward and reverse DNS resolution;
- time synchronization;
- test authentication;
- licensing;
- monitoring;
- successful backup and restore;
- documented network and service dependencies.

## Technologies

- Windows Server 2022

## Status

The source project documented AD/DNS as functional during the preparation/homologation stage, while final production validation and acceptance still required additional evidence.
