# Security

Este case documenta troubleshooting de infraestrutura e deve permanecer livre de informações sensíveis de produção.

## Não publicar

- endereços IP internos;
- IPv6 internos;
- hostnames e DNS internos;
- números de série e patrimônio;
- nomes de clientes ou ambientes;
- credenciais do iLO;
- screenshots com identificadores do ambiente;
- topologia detalhada que permita reconhecer a infraestrutura do cliente.

## Evidências

Antes de publicar qualquer screenshot ou fotografia:

1. remover ou mascarar IPs, hostnames e números de série;
2. revisar etiquetas físicas visíveis no equipamento;
3. evitar relatórios internos ou documentos timbrados;
4. publicar somente o necessário para demonstrar o troubleshooting.

O objetivo deste repositório é apresentar metodologia técnica, não expor informações operacionais de terceiros.
